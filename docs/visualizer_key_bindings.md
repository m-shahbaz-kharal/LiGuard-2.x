# Visualizer key bindings
| Key | Description |
| --- | --- |
| `left arrow` | Previous frame |
| `right arrow` | Next frame |
| `space` | Play/Pause |
| `delete` | Reset Playback |
| `[` | Jump to frame idx |
| `left mouse button` | Rotate (Arcball/Fly/Model/Environment) |
| `ctrl + left mouse button` | Pan |
| `shift + left mouse button` or `mouse wheel` | Zoom |
